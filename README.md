# Augmented Reality for Urban Planning
### Integrating Data Visualization with Physical Models

This project explores an Augmented Reality (AR) system that integrates with a physical city model to 
visualize simulation data in real-time. Users can interactively modify the model and observe 
immediate effects, enabling dynamic exploration of urban scenarios.

Tested on a 1:1000 scale city model using the Quest 3, the prototype demonstrates applications such as:
- Dynamic traffic simulation 
- Skyscraper shadow analysis 
- Emergency response scenarios (e.g., bomb discovery) 

By merging digital data with tangible representations, this system enhances spatial awareness, 
streamlines the urban design process, and supports data-driven decision-making for urban planners.

## Technical Details
- Meta Quest 3
- Unity Version 2022.3.11f1 LTS
- [Meta XR All-in-One SDK](https://assetstore.unity.com/packages/tools/integration/meta-xr-all-in-one-sdk-269657)
A cable link is required to run the application as the model is too large to run on the device.

I used the following free Assets from the Unity Asset store:
- [Low Poly Cars](https://assetstore.unity.com/packages/3d/vehicles/land/low-poly-cars-101798)
- [Urban Skyscrapers](https://assetstore.unity.com/packages/3d/environments/urban/urban-skyscrapers-289028)

Meta Room Setup is required to locate the table in the scene.
